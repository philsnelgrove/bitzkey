# bitzkey
AI research project

A "bitzkey" is a small virtual being with a neural network.  The purpose of
bitzkeys is to explore evolution and machine learning, with a virtual "ant 
farm".  A given number of bitzkeys will be instantiated into a generated virtual
environment for observation purposes.

The technology is Python (using the PyGame modules); however we are hand-rolling
the AI code, rather than making use of Python's well-known existing AI tools.
Since our purpose is to explore the differences in weighting algorithms, using
pre-built modules seemed counter-productive.

Currently none of this is implemented.  We are just spinning up the project and
working with architectural premises, so right now all it does is test printing 
of trace data.

More as it develops.
